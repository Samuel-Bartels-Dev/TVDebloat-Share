# LG OLED65C9PUA reference scope

Observed compatibility: firmware 03.50.31, webOS 4.5.0, Hearth 1.2.0.
See the [maintained customization reference](../../../docs/lg-c9-hearth-observations.md)
for wallpaper, Home/ribbon, screensaver, font, tile and troubleshooting procedures.
The reference separates working methods from version-specific limits and untested
persistence. It contains no household configuration or media inventory.

Native TVDebloat remains read-only. These findings do not provide an executable
write profile, rooting instructions, or validation for other firmware. Build any
candidate from fresh live discovery and the required approval/validation process.
